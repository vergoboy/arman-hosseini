arman-hosseini.ir سایت شخصی آرمان حسینی است: یک کارنما و یادداشت‌نامه ایستا و دوزبانه که با Astro ساخته شده و یک لایه SEO/AEO، یک سرویس مدیریت Node بدون وابستگی و یک خط لوله انتشار Obsidian دارد که یادداشت‌های Markdown و MDX را به انتشارهای اتمیک تبدیل می‌کند.

## arman-hosseini.ir چه مشکلی را حل می‌کند؟

این پروژه نوشته‌های فنی و یادداشت‌های پروژه‌ها را به دو زبان و بدون پایگاه داده، CMS یا فریم‌ورک سمت کلاینت منتشر می‌کند. سکوهای پویا برای محتوایی که بیشتر متن است، سرور، وابستگی و سربار زمان اجرا اضافه می‌کنند؛ این پروژه در عوض HTML پیش‌ساخته ارائه می‌دهد، محتوا را به‌صورت فایل زیر کنترل نسخه نگه می‌دارد و فقط یک سرویس کوچک برای ویرایش، اعتبارسنجی و انتشار اضافه می‌کند.

## arman-hosseini.ir چگونه کار می‌کند؟

Astro در زمان ساخت همه مسیرها را به HTML ایستا کامپایل می‌کند. یک سرویس جداگانه Node بدون وابستگی (`admin/`) محتوا را مدیریت و انتشارهای تازه می‌سازد، و nginx نسخه جاری را از طریق یک پیوند نمادین ارائه می‌دهد که تنها بعد از یک ساخت موفق جابه‌جا می‌شود.

پروژه در چهار لایه سازمان یافته است:

1. **نمایش** — مسیرهای Astro در `src/pages/` صفحات خانه، درباره، پروژه‌ها، یادداشت‌ها، برچسب‌ها و تماس را می‌سازند، به‌همراه `404`، `sitemap.xml`، `robots.txt`، `llms.txt`، فید RSS هر زبان و web manifest.
2. **محتوا** — فایل‌های Markdown و MDX زیر `src/content/{projects,journal}/{en,fa}` که با طرح‌واره `src/content.config.ts` اعتبارسنجی می‌شوند.
3. **SEO/AEO** — `src/lib/seo.ts` هر ورودی را به فراداده صفحه، کارت Open Graph/Twitter و یک گراف JSON-LD تبدیل می‌کند.
4. **مدیریت و انتشار** — سرویس Node در `admin/` محتوا را ویرایش و انتشارها را می‌سازد، و `deploy/` آن‌ها را از طریق nginx ارائه می‌دهد.

## چطور arman-hosseini.ir را نصب و اجرا کنم؟

پیش‌نیازها: Node.js 20 یا بالاتر (از بخش `engines` در `package.json`) و npm. زمان اجرای دیگری لازم نیست؛ سرویس مدیریت فقط از کتابخانه استاندارد Node استفاده می‌کند.

```bash
git clone https://github.com/vergoboy/arman-hosseini.git
cd arman-hosseini
npm ci
npm run dev        # سرور توسعه محلی
npm run build      # astro check && astro build → dist/
npm test           # تست‌های API پنل (node --test admin/test/*.test.mjs)
```

دستورهای معتبر `package.json` این‌ها هستند:

| Script | دستور | کاربرد |
| --- | --- | --- |
| `npm run dev` | `astro dev` | سرور توسعه محلی |
| `npm run build` | `astro check && astro build` | بررسی نوع و ساخت در `dist/` |
| `npm run preview` | `astro preview` | پیش‌نمایش خروجی ساخته‌شده |
| `npm test` | `node --test admin/test/*.test.mjs` | تست‌های API پنل |
| `npm run admin` | `node admin/server.mjs` | اجرای سرویس مدیریت (پیش‌فرض `127.0.0.1:4322`) |
| `npm run deploy` | `bash scripts/deploy.sh` | ساخت و همگام‌سازی `dist/` با سرور به‌صورت نسخه تازه |

## چطور arman-hosseini.ir را پیکربندی کنم؟

سرویس مدیریت و فرایند ساخت مجموعه کوچکی از متغیرهای محیطی را می‌خوانند. فقط نام‌ها — هرگز رمز یا کلید را در مخزن نگه ندارید.

| متغیر | کاربرد | پیش‌فرض |
| --- | --- | --- |
| `SITE_DIR` | ریشه سورس سایت | ریشه پروژه |
| `DATA_DIR` | پوشه داده پنل (نشست‌ها، ساخت‌ها، صندوق ورودی) | `./.admin-data` |
| `RELEASES_DIR` | محل نگهداری نسخه‌های ساخته‌شده | `./releases` |
| `CURRENT_LINK` | پیوند نمادینی که nginx ارائه می‌دهد | `./current` |
| `ADMIN_HOST` | نشانی اتصال پنل | `127.0.0.1` |
| `ADMIN_PORT` | درگاه پنل | `4322` |
| `BUILD_CMD` | دستوری که پنل برای ساخت اجرا می‌کند | `npm run build:site` |
| `KEEP_RELEASES` | تعداد نسخه‌های نگه‌داشته‌شده | `5` |
| `SITE_URL` | نشانی canonical سایت | `https://arman-hosseini.ir` |

تنظیمات انتشار که رمز نیستند در `deploy.config.json` قرار دارند (host، port، user، `remotePath`، `identityFile`، `localDir`، `buildCommand`، `exclude`). هر نوع اعتبارنامه باید در `.env` (نادیده‌گرفته‌شده در git) بماند؛ `scripts/deploy.sh` اگر `deploy.config.json` فیلدی مانند password، passphrase، privateKey، token یا secret داشته باشد، از اجرا سر باز می‌زند.
