This site is deliberately boring in the places that matter for speed and discoverability, and a little unusual where it makes my life easier.

## Static first

Every page is plain HTML generated by Astro. There is no client-side framework; the only JavaScript is a few lines for the theme toggle and a privacy-friendly page-view beacon. Fonts are self-hosted and the stylesheet is inlined or tiny.

## One source of truth for SEO

Each page carries its own title, description, keywords, featured image with alt text, publish and update dates and a Schema.org type. The dashboard stores overrides next to the content instead of inside it, so re-publishing a note from Obsidian never erases an SEO tweak.

## From Obsidian to the web

Notes live in my vault. The Studio plugin previews the page with the site's own styles, compiles the MDX, converts Obsidian syntax such as image embeds, and uploads the page together with its images and videos. A broken page is refused with the file and line number, and a valid one waits in an inbox for my approval.

## Atomic releases

Each build goes into its own release directory and a symlink is switched only after the build succeeds. A bad build can never take the site down, and rolling back is one click.
